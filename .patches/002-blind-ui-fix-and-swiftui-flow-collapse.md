# 002 — Вёрстку проверяй глазами; SwiftUI-флоу не самосайзится по высоте

**Дата:** 2026-06-29 · Фаза: разработка (M1, слой «группировка»)

## Грабли
Sheet группировки: чипы имён файлов **наезжали на подзаголовок** (file-strip получал ~0 высоты).
1. **«Зелено» ≠ «правильно».** Developer закрыл слой с `selfcheck_grouping` 22/22 + регрессии +
   `build exit 0` — но self-check проверяет БЭКЕНД (scan/dispatcher/манифесты), вёрстку он не видит.
   Наложение поймал только Юрка живым снимком окна по window-id.
2. **Слепая правка вёрстки.** Developer не видит результат своими глазами. 1-й фикс был
   «по рассуждению» (убрать `.frame(height:)`, понадеяться на самосайз `ZStack`) — **не сработал**,
   наложение осталось точь-в-точь. Это съело 1 переделку из лимита 2.
3. **SwiftUI-ловушка.** `ZStack` с детьми, разложенными через `alignmentGuide` (классический
   wrapping-flow), **НЕ растягивается по высоте флоу** — берёт высоту одного самого высокого
   ребёнка. А паттерн `GeometryReader { flow }.frame(height: totalHeight)` со стартом
   `totalHeight = 0` схлопывает высоту в 0 на первом кадре (петля обратной связи: GR жаден по
   обеим осям → предлагает детям 0 → зонд меряет 0 → 0 навсегда).

## Правило на будущее
- **Любой новый/правленый UI от субагента → Юрка сверяет в НАСТОЯЩЕМ окне** (window-id снимок,
  при нужде zoom через PIL) ДО пометки «готово». `compile + self-check green` — необходимо, не
  достаточно. Бэкенд-self-check НИКОГДА не подтверждает раскладку.
- **SwiftUI wrapping/flow — запрет на самоизмерение высоты через `GeometryReader`.** Для рядов
  чипов: меряй ширину каждого синхронно `NSAttributedString.size()` тем же шрифтом, **пакуй в
  ряды в Swift** и рисуй `VStack { HStack(ряд) }`. Высота = сумма рядов → **корректно по
  построению**, без `@State`-высоты, без петли, без «прыжка» первого кадра. (Сработало на 2-м фиксе.)
- **Слепому developer'у на UI-фикс — давай ГОТОВЫЙ детерминированный подход**, а не «определи
  высоту». Не давай ему итерировать на хрупком паттерне измерения — это и есть класс бага.
- Лимит переделок реален: 1-я слепая попытка сожгла итерацию. Если бы 2-я тоже мимо — это был бы
  «долг процесса» (менять процесс, а не баг). Прескриптивность во 2-й попытке спасла.
